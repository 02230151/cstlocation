# CST Campus Guide (React)

This is the editable React + Vite version of the campus map homepage. The QGIS-exported GeoJSON is kept in `public/layers` and loaded by the app at startup.

## Run locally

In PowerShell, open this folder and run:

```powershell
npm install
npm run dev
```

Open the local address Vite prints (usually `http://localhost:5173`). The basemap tiles and fonts need an internet connection.
